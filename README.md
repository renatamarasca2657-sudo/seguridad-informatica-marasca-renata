# 1. La seguridad informática es el conjunto de medidas que protegen computadoras, dispositivos y datos. Es importante porque evita robos de información y ataques informáticos.

# 2. La confidencialidad significa que solo las personas autorizadas pueden acceder a la información. La integridad evita que los datos sean modificados incorrectamente y la disponibilidad permite acceder a ellos cuando se necesitan.

# 3. Un virus es un programa que infecta archivos y puede dañar una computadora. El malware es cualquier programa malicioso y el ransomware bloquea archivos para pedir dinero a cambio de recuperarlos.

# 4. El phishing es un engaño que busca robar información personal, como contraseñas o datos bancarios. Podemos reconocerlo por mensajes sospechosos, enlaces extraños o pedidos urgentes de información.

# 5. La ingeniería social es una técnica que utilizan los delincuentes para engañar a las personas y conseguir información privada. Generalmente, se hacen pasar por alguien de confianza.

# 6. Una contraseña segura debe ser larga y combinar letras mayúsculas, minúsculas, números y símbolos. También debe ser difícil de adivinar y diferente para cada cuenta.

# 7. Un hacker White Hat utiliza sus conocimientos para mejorar la seguridad de los sistemas de manera autorizada. En cambio, un Black Hat los utiliza para robar información o causar daños.

# 8. Las copias de seguridad permiten guardar una copia de nuestros archivos importantes. Son útiles porque permiten recuperar la información si se pierde, se daña el dispositivo o sufrimos un ataque informático.
